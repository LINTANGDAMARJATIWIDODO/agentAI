# Automated QA & Testing Standards

This skill provides comprehensive test automation methodologies, API regression harnesses, and quality gatekeeping protocols.

## Core Capabilities
- **Playwright Automation**: Headless browser automation, visual diffing, accessibility tree inspection, and network stubbing.
- **API Contract Verification**: Strict schema conformance, HTTP status codes, latency SLAs (<50ms p95), and edge case boundaries.
- **Regression Suites**: Smoke, sanity, and full regression test matrices with automated failure reporting.
- **Defect Classification**: Root cause analysis (RCA), reproducible bug reporting, and defect severity/priority triage.
