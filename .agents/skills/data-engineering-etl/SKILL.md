# Data Engineering & ETL Pipeline Standards

This skill provides production standards for building resilient data pipelines, dimensional warehouses, and automated data quality assertions.

## Core Capabilities
- **Database Modeling**: Normalized schemas (3NF) for OLTP and Dimensional Star/Snowflake schemas for OLAP.
- **Pipeline Architecture**: Idempotent batch and streaming jobs, atomic transactions, and automated error replay dead-letter queues.
- **Data Quality Assertions**: Uniqueness checks, non-null validations, referential foreign key integrity, and anomaly range thresholds.
- **Data Governance**: Master data management (MDM), data dictionary indexing, and lineage tracking.
