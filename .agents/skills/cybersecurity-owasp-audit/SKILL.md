# Cybersecurity & OWASP Security Audit Standards

This skill provides procedural guidelines for conducting comprehensive security audits, identifying code vulnerabilities, and enforcing zero-trust architecture.

## Core Capabilities
- **OWASP Top 10 Coverage**: Detection of Broken Access Control, Cryptographic Failures, Injections, Insecure Design, Security Misconfigurations, and Vulnerable Components.
- **SAST & Secret Detection**: Automated regex scanning for AWS keys, private tokens, hardcoded passwords, and unescaped database queries.
- **Header & Protocol Hardening**: Content-Security-Policy (CSP), Strict-Transport-Security (HSTS), CORS strict origin allowlisting, and X-Content-Type-Options.
- **Threat Modeling**: STRIDE methodology (Spoofing, Tampering, Repudiation, Information Disclosure, Denial of Service, Elevation of Privilege).
