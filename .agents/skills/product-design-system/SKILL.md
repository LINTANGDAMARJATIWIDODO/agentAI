# Product Design System & UI/UX Standards

This skill provides comprehensive instructions for designing scalable design systems, typography hierarchies, token architecture, and accessibility conformance.

## Core Capabilities
- **Token Engineering**: Primitive, semantic, and component token structures (colors, spacing, elevations, radiuses).
- **Figma Token Studio Synchronization**: Mapping JSON token schemas to Figma styles and CSS variables.
- **Accessibility Verification**: Validating WCAG 2.1 AA contrast ratios (4.5:1 for normal text, 3.0:1 for large/graphical elements).
- **Component Contracts**: Strict prop interfaces for Buttons, Inputs, Modals, Data Tables, and Navigation Bars.
