# ARSIP REGULASI SPBE PEMPROV DKI JAKARTA (REPOSITORI SPBE)
> **Sumber Dokumen:** Repositori SPBE DKI Jakarta (repositorispbe.jakarta.go.id)  
> **Klasifikasi:** Dokumen Regulasi Daerah Resmi  
> **Penerbit:** Dinas Komunikasi, Informatika dan Statistik Provinsi DKI Jakarta

---

### KETENTUAN ARSITEKTUR SISTEM PEMERINTAHAN BERBASIS ELEKTRONIK (SPBE)
1. **Peraturan Gubernur DKI Jakarta No. 12 Tahun 2023 tentang Penyelenggaraan SPBE:**
   - Mewajibkan interoperabilitas data lintas Organisasi Perangkat Daerah (OPD) melalui Satu Data Jakarta (`data.jakarta.go.id`).
   - Standar keamanan informasi berbasis ISO 27001 dan kepatuhan penuh terhadap undang-undang pelindungan data pribadi.
   - Pemanfaatan pusat data terintegrasi (Government Cloud) dengan kedaulatan data di wilayah DKI Jakarta.
2. **Kriteria Kemitraan Teknologi Pihak Ketiga:**
   - Vendor teknologi dan konsultan AI wajib menyediakan API terbuka (*Open API*) dengan dokumentasi Swagger/OpenAPI.
   - Menyediakan audit trail transparan dan tidak membocorkan data masyarakat ke server luar negeri.
